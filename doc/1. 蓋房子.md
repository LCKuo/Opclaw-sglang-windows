# WSL2 + GPU + SGLang 安裝指南（Windows）

本指南會完成以下環境：

Windows → WSL2 → Ubuntu → Python venv → SGLang

最後會測試指令：

python -m sglang.launch_server --help

------------------------------------------------------------------------

# 一、安裝 WSL2

在 **PowerShell（系統管理員）**執行：

    wsl --install

安裝完成後 **重新開機**。

------------------------------------------------------------------------

## 安裝 Ubuntu

重新開機後執行：

    wsl -l -v

應該會看到：

    NAME      STATE      VERSION
    Ubuntu    Running    2

------------------------------------------------------------------------

## 常用 WSL 指令

列出所有 WSL VM

    wsl -l -v

啟動 Ubuntu

    wsl -d Ubuntu

關閉 Ubuntu

    wsl --terminate Ubuntu

設定 Ubuntu 為預設

    wsl --set-default Ubuntu

------------------------------------------------------------------------

# 二、確認 GPU 能被 WSL 使用

如果你有 NVIDIA GPU，需要安裝 WSL GPU Driver

https://developer.nvidia.com/cuda/wsl

安裝完成後重新開機。

------------------------------------------------------------------------

## 在 WSL 測試 GPU

    wsl -d Ubuntu

執行

    nvidia-smi

如果成功會看到 GPU 資訊，例如

    +-----------------------------------------------------------------------------------------+
    | NVIDIA-SMI 595.54                 Driver Version: 595.79         CUDA Version: 13.2     |
    | GPU  Name                 Memory-Usage |
    | 0    NVIDIA GeForce RTX 4070           |
    +-----------------------------------------------------------------------------------------+

代表 WSL 已成功使用 GPU。

------------------------------------------------------------------------

# 三、安裝 Python 環境

更新系統

    sudo apt update && sudo apt upgrade -y

安裝 Python 與工具

    sudo apt install python3 python3-pip python3-venv git -y

確認版本

    python3 --version
    pip3 --version

------------------------------------------------------------------------

# 四、建立 Python 虛擬環境（venv）

回到 Home

    cd ~

建立虛擬環境

    python3 -m venv sglang

啟動環境

    source sglang/bin/activate

成功後 prompt 會出現

    (sglang) user@machine:~$

------------------------------------------------------------------------

# 五、升級 pip

    pip install --upgrade pip setuptools wheel

------------------------------------------------------------------------

# 六、安裝 SGLang

    pip install "sglang[all]"

安裝時間約 5～10 分鐘。

------------------------------------------------------------------------

# 七、確認 SGLang 安裝成功

執行

    python -m sglang.launch_server --help

如果成功會看到

    usage: launch_server.py [-h] --model-path MODEL_PATH ...

代表 SGLang server 已可啟動。
