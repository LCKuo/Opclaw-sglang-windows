# WSL2 + GPU + SGLang 完整安裝與修復指南

本指南將帶領你完成從 Windows 底層到 SGLang 推理伺服器啟動的全過程，並針對常見的 `libnuma` 缺失與 `sgl_kernel` 相容性問題進行修復。

---

## 核心架構
`Windows 11` → `WSL2 (Ubuntu 22.04+)` → `NVIDIA Driver` → `Python venv` → `SGLang`

---

## 一、安裝 WSL2 與 Ubuntu

### 1. 安裝指令
以 **管理員權限** 開啟 PowerShell 並執行：
```powershell
wsl --install
```
安裝完成後請 **重新啟動電腦**。

### 2. 確認狀態
重啟後在 PowerShell 執行：
```powershell
wsl -l -v
```
若看到 `Ubuntu` 且版本為 `2` 即代表成功。

### 3. 常用 WSL 管理指令
* **啟動**：`wsl -d Ubuntu`
* **關閉**：`wsl --terminate Ubuntu` (僅關閉 Ubuntu)
* **全域重啟**：`wsl --shutdown` (關閉所有 WSL 服務，含 Docker)
* **設定預設**：`wsl --set-default Ubuntu`

---

## 二、配置 NVIDIA GPU 環境

### 1. 驅動程式
請確保 Windows 已安裝最新版 NVIDIA 驅動。WSL2 會自動映射硬體，不需在 Linux 內重複安裝驅動。
[NVIDIA WSL 驅動下載](https://developer.nvidia.com/cuda/wsl)

### 2. 進入 Ubuntu 並測試
執行 `wsl -d Ubuntu` 進入 Linux，輸入：
```bash
nvidia-smi
```
若看到 GPU 型號（如 **RTX 4070**）與 CUDA 版本資訊，代表連通成功。

---

## 三、安裝系統依賴與 Python

更新系統並安裝必要的編譯工具與 **libnuma**（SGLang 運行必備）：

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv git libnuma-dev -y
```
> **注意**：`libnuma-dev` 修復了常見的 `libnuma.so.1` 找不到的錯誤。

---

## 四、建立 Python 虛擬環境 (venv)

為了保持系統乾淨，建議建立獨立環境：

```bash
cd ~
python3 -m venv sglang
source sglang/bin/activate
```
啟動後，你的命令列前方應出現 `(sglang)` 字樣。

---

## 五、安裝與優化 SGLang

### 1. 基礎安裝
```bash
pip install --upgrade pip setuptools wheel
pip install "sglang[all]"
```

### 2. 針對 RTX 40 系列 (SM89) 進行修復與優化
若你使用 RTX 4070/4080/4090，請務必執行此步驟以確保 `common_ops` 支援：
```bash
pip install --upgrade sgl_kernel
```

---

## 六、硬體架構校驗 (SM Check)

在虛擬環境中執行以下 Python 指令，確認 PyTorch 與 GPU 架構匹配：

```bash
python -c "import torch; print(f'Device: {torch.cuda.get_device_name(0)} | Capability: {torch.cuda.get_device_capability(0)}')"
```
**預期輸出：**
`Device: NVIDIA GeForce RTX 4070 | Capability: (8, 9)`

---

## 七、啟動 SGLang 推理伺服器

執行以下指令啟動模型（以 Qwen 2.5 為例）：

```bash
python -m sglang.launch_server   --model-path Qwen/Qwen2.5-7B-Instruct   --port 30000
```

### 測試伺服器是否響應
另開一個終端機執行：
```bash
python -m sglang.launch_server --help
```

---

## 📖 常見問題排解 (Troubleshooting)

| 問題 | 解決方案 |
| :--- | :--- |
| `OSError: libnuma.so.1` | 執行 `sudo apt install libnuma-dev -y` |
| `sgl_kernel` 報錯 | 執行 `pip install --upgrade sgl_kernel` |
| WSL 佔用記憶體過高 | 在 Windows `%USERPROFILE%` 下建立 `.wslconfig` 限制 `memory=8GB` |
