## 一、安裝 WSL2
- 在 **PowerShell（管理員）**執行：
```bash
wsl --install
```
- 安裝完成後重開機。
- 然後安裝 Ubuntu。
- 確認：(列出所有VM)
```bash
wsl -l -v
```
應該會看到：
```bash
Ubuntu    Running    Version 2
```
啟動名為 Ubuntu 的 wsl
```bash
wsl -d Ubuntu
```
關閉 名為 Ubuntu 的 wsl
```bash
wsl --terminate Ubuntu
```

## 三、裝 python
- 更新系統與安裝必要工具
- 建議先更新：
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install python3 python3-pip python3-venv git -y
```
確認 Python：
```bash
python3 --version
pip3 --version
```
