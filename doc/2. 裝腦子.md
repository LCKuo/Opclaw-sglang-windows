## 裝sglang + Qwen3.5-27B
```bash
# 1️⃣ 更新系統
sudo apt update && sudo apt upgrade -y

# 2️⃣ 安裝必要工具
sudo apt install -y python3 python3-pip python3-venv git build-essential wget curl

# 3️⃣ 建立 Python 虛擬環境
python3 -m venv ~/sglang_env
source ~/sglang_env/bin/activate

# 4️⃣ 升級 pip
pip install --upgrade pip

# 5️⃣ 安裝 SGLang（含 GPU 加速依賴）
pip install "sglang[all]"

# 6️⃣ 驗證 PyTorch GPU 是否可用
python -c "import torch; print('GPU available:', torch.cuda.is_available())"

# 7️⃣ 啟動 SGLang server 使用 Qwen3.5-27B
sglang-server --model-path Qwen/Qwen3.5-27B-Instruct --host 0.0.0.0 --port 30000
```
